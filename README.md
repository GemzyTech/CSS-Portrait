#CSS Portrait

A portrait made with **HTML & CSS — for someone special.**

## 💭 About

I can't really draw, so I decided to try something different.

Instead of using a pencil or a drawing app, I created this portrait using **HTML, CSS, and text**. The image is built from repeated words and carefully placed elements to create the final portrait.

It's not perfect, but I made it from scratch as a small personal project for someone who means a lot to me.

## ✨ What Makes It Special

* 🖤 Made entirely with HTML & CSS
* 📝 Uses text as part of the portrait
* 🎨 No drawing software used
* 💻 Created from scratch
* ❤️ Made as a personal gift

## 🛠️ Built With

**HTML5**
Used to structure the project and its elements.

**CSS3**
Used to control the layout, text, colors, positioning, and overall appearance.
