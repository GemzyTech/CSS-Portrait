# CSS Portrait

A small portrait made with **HTML and CSS** for someone special.

## 💭 About the Project

I'm not really good at drawing, so instead of using a pencil and paper, I decided to create a portrait using **code**.

I made this using simple HTML elements and CSS styling, putting together different shapes, colors, and details to create the portrait.

It may not be perfect, but I made it myself — and that's what makes it special. ❤️

## 🛠️ Built With

* HTML5
* CSS3

## ✨ What I Learned

While making this project, I practiced:

* Creating shapes with CSS
* Positioning elements
* Working with colors and borders
* Combining HTML and CSS
* Turning an idea into something visual
